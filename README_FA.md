# اسکنر ۳۰۰ ارز برتر Kraken — SQZMOM + SMC — تایم‌فریم ۳۰ دقیقه

## مشخصات نهایی
- فهرست مرجع: ۳۰۰ ارز اول بر اساس Market Cap از CoinGecko (۲۵۰ مورد صفحه اول + ۵۰ مورد بعدی).
- صرافی داده: Kraken؛ برای هر ارز بازار Perpetual در صورت وجود و در غیر این صورت بازار Spot انتخاب می‌شود. اولویت جفت‌ارز با USD، سپس USDT، USDC و EUR است؛ در اولویت یکسان، Futures مقدم است.
- فقط دارایی‌هایی از ۳۰۰ رتبه اول که در Kraken بازار قابل‌استفاده دارند قابل اسکن هستند. مواردی که در Kraken فهرست نشده‌اند در گزارش تعداد تطبیق‌داده‌شده مشخص می‌شوند و برایشان سیگنال ساختگی صادر نمی‌شود.
- تایم‌فریم تمام داده‌ها: ۳۰ دقیقه؛ فقط کندل‌های بسته‌شده.
- اجرای GitHub Actions: هر ۵ دقیقه (زمان‌بندی GitHub تقریبی است).
- خروجی: هشدار تلگرام؛ هیچ سفارشی ثبت نمی‌شود و معامله خودکار وجود ندارد.

## منطق BTC؛ تعیین‌کننده فاز بازار
- BTC با SQZMOM محاسبه‌شده از کندل‌های ۳۰ دقیقه‌ای Kraken بررسی می‌شود؛ برای BTC تأیید SMC لازم نیست.
- قله معتبر: قله مثبت با دو کندل قبل و دو کندل بسته‌شده بعد از نقطه قله که کاهش میله‌ها را تأیید کنند؛ رویداد SELL است.
- دره معتبر: دره منفی با دو کندل قبل و دو کندل بسته‌شده بعد از نقطه دره که افزایش میله‌ها را تأیید کنند؛ رویداد BUY است.
- هیچ ضریب قدرت، آستانه ارتفاع یا فیلتر دامنه‌ای استفاده نمی‌شود.
- در هر تغییر فاز، ابتدا هشدار BTC ارسال می‌شود. پس از آن فقط سیگنال‌های هم‌جهت آلت‌کوین‌ها بررسی و ارسال می‌شوند.
- تا زمانی که قله/دره تأییدشده BTC موجود نباشد، اسکن آلت‌کوین‌ها متوقف می‌ماند.
- سیگنال آلت‌کوینی که زمان کندل آن قبل از شروع فاز جاری BTC باشد ارسال نمی‌شود.

## منطق سیگنال ارزها
1. SQZMOM با همان تنظیمات و فرمول قبلی محاسبه می‌شود.
2. SELL: سه میله بسته‌شده همگی بالای صفر باشند و میله وسط قله محلی باشد.
3. BUY: سه میله بسته‌شده همگی زیر صفر باشند و میله وسط دره محلی باشد.
4. SMC تأییدکننده است: تماس سایه هرکدام از پنج کندل بسته‌شده آخر با هر ناحیه SMC هم‌جهت کافی است.
5. سیگنال فقط وقتی ارسال می‌شود که با فاز BTC هم‌جهت باشد.
6. هر هشدار ارز، جهت جاری SQZMOM بیت‌کوین را نیز صریحاً نمایش می‌دهد.
7. در هر کندل و جهت، از هر بازار فقط یک هشدار ارسال می‌شود.

## منابع داده و API
- رتبه‌بندی Market Cap: `https://api.coingecko.com/api/v3/coins/markets`
- فهرست قراردادهای Kraken Futures: `https://futures.kraken.com/derivatives/api/v3/instruments`
- کندل Futures: `https://futures.kraken.com/api/charts/v1/trade/{symbol}/30m`
- فهرست جفت‌ارز Spot: `https://api.kraken.com/0/public/AssetPairs`
- کندل Spot: `https://api.kraken.com/0/public/OHLC?interval=30`
- برای دریافت داده بازار Kraken کلید API خصوصی لازم نیست. CoinGecko Public API ممکن است محدودیت نرخ درخواست داشته باشد.

## نصب در GitHub
1. ZIP را روی دستگاه استخراج کنید.
2. تمام محتویات پوشه `Kraken_Derivatives_Scanner` را در ریشه Repository قرار دهید؛ پوشه مخفی `.github/workflows/scan.yml` باید حفظ شود.
3. در Repository → Settings → Secrets and variables → Actions این دو Secret را بسازید یا Secretهای قبلی را حفظ کنید:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. در Settings → Actions → General، دسترسی Workflow به `Read and write` فعال باشد تا `state.json` به‌روزرسانی شود.
5. از زبانه Actions، Workflow را با `Run workflow` دستی اجرا کنید.
6. در اجرای اول، لاگ Actions تعداد ۳۰۰ دارایی مرجع و تعداد دارایی‌های قابل‌تطبیق با Kraken را نشان می‌دهد.

## فایل‌ها
- `scanner.py`: دریافت رتبه‌بندی، نگاشت بازارهای Kraken، کنترل فاز BTC و ارسال هشدار.
- `indicator_engine.py`: محاسبات SQZMOM، فرمول سیگنال قبلی، تأیید SMC و تشخیص قله/دره BTC.
- `.github/workflows/scan.yml`: اجرای خودکار هر پنج دقیقه.
- `state.json`: جلوگیری از ارسال تکراری هشدارها و نگهداری رویداد BTC.
- `test_engine.py`, `test_scanner_api.py`: تست‌های آفلاین.

## تست
```bash
python -m pip install -r requirements.txt
python -m unittest -v
```

تست‌های آفلاین بررسی می‌کنند که منطق محاسباتی، نگاشت نمادها، دریافت دو صفحه رتبه‌بندی، حذف کندل باز و تشخیص قله/دره بدون ضریب درست عمل کنند. تست آفلاین به معنی تأیید اتصال زنده نیست؛ اتصال واقعی Kraken و CoinGecko در اولین اجرای GitHub Actions مشخص می‌شود.
