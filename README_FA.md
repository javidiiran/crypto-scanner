# اسکنر سه — Kraken Futures — تایم‌فریم ۳۰ دقیقه

این بسته مستقل است و فقط دو سورس Pine ارسالی را پیاده‌سازی می‌کند:
1. SQZMOM_LB از LazyBear
2. Order Blocks Zones with Signals از Uncle_the_shooter

## قوانین فرماندهی بیت‌کوین و سیگنال‌ها
- بازار فقط Kraken Futures و قراردادهای دائمی قابل معامله است؛ بیت‌کوین ابتدا با قرارداد XBT/USD بررسی می‌شود.
- تایم‌فریم همه محاسبات ۳۰ دقیقه است و کندل در حال تشکیل کاملاً کنار گذاشته می‌شود.
- **شروع فرمان SELL بیت‌کوین:** دو کندل بسته‌شدهٔ متوالی SQZMOM با رنگ سبز تیره (`green`) و وجود تماس حداقل یکی از چهار کندل بسته‌شدهٔ اخیر با OB یا FVG نزولی.
- **شروع فرمان BUY بیت‌کوین:** دو کندل بسته‌شدهٔ متوالی SQZMOM با رنگ قرمز تیره (`maroon`) و وجود تماس حداقل یکی از چهار کندل بسته‌شدهٔ اخیر با OB یا FVG صعودی.
- پس از سیگنال بیت‌کوین، اسکن آلت‌کوین‌ها از کندل ۳۰ دقیقه‌ای بعدی آغاز می‌شود و فقط سیگنال‌های هم‌جهت با بیت‌کوین، با تأیید OB/FVG، اجازهٔ ارسال دارند.
- مجوز اسکن دقیقاً چهار کندل بسته‌شدهٔ بعد از کندل سیگنال بیت‌کوین اعتبار دارد.
- **توقف فرمان SELL:** با بسته‌شدن حتی یک کندل SQZMOM سبز روشن (`lime`) در بیت‌کوین، اسکن آلت‌کوین‌ها فوراً متوقف می‌شود.
- **توقف فرمان BUY:** با بسته‌شدن حتی یک کندل SQZMOM قرمز روشن (`red`) در بیت‌کوین، اسکن آلت‌کوین‌ها فوراً متوقف می‌شود.
- پایان چهار کندل نیز مجوز را می‌بندد؛ پس از توقف یا پایان پنجره، اسکن آلت‌کوین‌ها تا سیگنال معتبر جدید بیت‌کوین انجام نمی‌شود.
- کنار سیگنال بیت‌کوین RSI بیت‌کوین و کنار هر سیگنال آلت‌کوین RSI همان ارز و RSI بیت‌کوین درج می‌شود (RSI با دورهٔ ۱۴).
- رنگ‌های روشن سیگنال شروع نیستند؛ فقط برای توقف مجوز در جهت تعریف‌شده استفاده می‌شوند.
- تماس با OB/FVG با کل محدودهٔ High–Low کندل سنجیده می‌شود؛ سایه و بدنه هر دو لحاظ می‌شوند. OB و FVG اعتبار یکسان دارند.
- باکس‌های شکسته، منقضی‌شده طبق سورس، یا قدیمی‌تر از ۵۰۰ کندل معتبر نیستند.
- هشدار تکراری برای یک نماد/جهت/کندل بسته‌شده ارسال نمی‌شود؛ وضعیت فرمان BTC نیز در `state.json` نگهداری می‌شود تا بین اجراهای GitHub Actions از بین نرود.

## فایل مهم AB
`AB.py` فایل تنظیمات اجرایی و نقطه شروع اصلی اسکنر است. در GitHub Actions نیز همین فایل اجرا می‌شود. موتور محاسباتی اندیکاتورها در `ob_sqzmom_engine.py` قرار دارد.

## فایل‌ها
- `AB.py`: فایل AB، کنترل فرمان بیت‌کوین و اجرای اصلی
- `ob_sqzmom_engine.py`: موتور محاسبات SQZMOM و OB/FVG
- `notifier.py`: پیام‌های شروع/توقف بیت‌کوین و سیگنال آلت‌کوین‌ها همراه RSI
- `settings.py`: تنظیمات مرکزی
- `kraken_client.py`: دریافت قراردادها و کندل‌ها از Kraken Futures
- `notifier.py`: ارسال هشدار تلگرام
- `scanner.py`: لانچر سازگار جایگزین برای اجرای محلی
- `indicators.py`: نام سازگار برای import موتور
- `state.json`: حافظه جلوگیری از هشدار تکراری
- `.github/workflows/scan.yml`: اجرای خودکار هر پنج دقیقه
- `.env.example`: نمونه تنظیمات تلگرام محلی
- `requirements.txt`: وابستگی‌ها

## راه‌اندازی GitHub
1. محتوای ZIP را در ریشه مخزن GitHub بارگذاری کن.
2. در Settings → Secrets and variables → Actions دو Secret بساز: `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`.
3. از Actions، ورک‌فلو Scanner 3 - Kraken Futures را با Run workflow اجرا کن.
4. ورک‌فلو هر ۵ دقیقه اجرا می‌شود تا بسته‌شدن کندل ۳۰ دقیقه‌ای را از دست ندهد؛ تصمیم‌ها فقط یک‌بار برای هر کندل بسته‌شده گرفته می‌شوند. اسکن بازار فقط در پنجرهٔ چهارکندلی مجاز بیت‌کوین انجام می‌شود.

## اجرای محلی
```bash
python -m pip install -r requirements.txt
cp .env.example .env
# مقدار واقعی Bot Token و Chat ID را داخل .env قرار بده
python AB.py
```
بدون توکن تلگرام، پیام در خروجی برنامه چاپ می‌شود.

## API و محدودیت اعتبارسنجی
از endpoint عمومی Kraken Futures برای کندل‌های `trade` با resolution برابر `30m` استفاده می‌شود؛ این API برای خواندن داده به کلید خصوصی نیاز ندارد. زمان کندل در پاسخ API بر حسب میلی‌ثانیه است و پارامترهای from/to بر حسب ثانیه هستند. مستندات رسمی: https://docs.kraken.com/api/docs/futures-api/charts/candles

کدها از نظر نحوی و تست‌های محلی کنترل می‌شوند؛ برای اطمینان نهایی از تطابق عددی کامل با TradingView، باید خروجی چند نماد و چند کندل به‌صورت زنده مقایسه شود.
