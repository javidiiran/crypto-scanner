# اسکنر ۴ — Kraken Futures | 15m

اسکنر Python برای تمام قراردادهای قابل معامله Kraken Futures. تمام محاسبات فقط با کندل‌های بسته‌شده ۱۵ دقیقه‌ای انجام می‌شود. هر نماد مستقل تحلیل می‌شود؛ بیت‌کوین فقط فیلتر جهت نهایی سیگنال‌هاست و نوع سیگنال خود BTC هیچ نقشی در صدور سیگنال سایر ارزها ندارد.

## قوانین نهایی سیگنال

### ۱) B-Xtrender
- فقط دو رنگ آخرِ محاسبه‌شده از کندل‌های بسته‌شده بررسی می‌شود.
- تغییر قرمز به سبز = سیگنال اولیه BUY؛ آخرین کندل باید سبز باشد.
- تغییر سبز به قرمز = سیگنال اولیه SELL؛ آخرین کندل باید قرمز باشد.
- هیچ کندل در حال تشکیل وارد محاسبات نمی‌شود.

### ۲) Delta Reaction Zones [BOSWaves]
- زون سبز، تأیید BUY است؛ زون قرمز، تأیید SELL است.
- تماس یا هم‌پوشانی High/Low حداقل یکی از شش کندل بسته‌شده آخر با زون فعال هم‌رنگ کافی است؛ لازم نیست کندل داخل زون بسته شود.
- زون تا زمان ابطال/حذف طبق منطق اندیکاتور فعال می‌ماند.
- اگر هر دو باکس فعال با یکدیگر هم‌پوشانی داشته باشند، آن نماد هیچ سیگنالی نمی‌دهد؛ این قانون برای BUY و SELL یکسان و وتوی قطعی است.

### ۳) فیلتر BTC
ابتدا BTC بررسی و در ابتدای پیام وضعیت سیگنال آن به‌همراه رنگ دو کندل بسته‌شده آخر B-Xtrender گزارش می‌شود.
- سبز، سبز: فقط BUY مجاز است.
- قرمز، قرمز: فقط SELL مجاز است.
- رنگ‌های متفاوت: BUY و SELL هر دو مجازند.
- سیگنال BUY/SELL خود بیت‌کوین هیچ اثری بر سیگنال سایر نمادها ندارد.
- همه نمادها مستقل اسکن می‌شوند؛ فیلتر BTC بعد از تحلیل نمادها و فقط برای تعیین جهت‌های مجاز اعمال می‌شود.
- اگر داده BTC کهنه باشد یا دو رنگ آخر قابل تشخیص نباشد، هیچ سیگنالی اعلام نمی‌شود و هشدار داده نمایش داده می‌شود.

### ۴) تازگی داده
- کندل بسته‌شده وقتی کهنه محسوب می‌شود که بیش از ۱۵ دقیقه از زمان بسته‌شدن آن گذشته باشد.
- نماد دارای کندل کهنه سیگنال نمی‌دهد و در گزارش تشخیصی ثبت می‌شود.
- اگر کندل BTC کهنه باشد، جهت فیلتر قابل اعتماد نیست؛ همه نمادها همچنان اسکن می‌شوند اما هیچ سیگنالی اعلام نمی‌شود.

## قالب پیام تلگرام
ابتدا وضعیت سیگنال BTC و رنگ دو کندل آخر آن می‌آید. برای هر سیگنال ارز فقط این موارد نمایش داده می‌شود:
- BUY: دایره سبز 🟢 کنار نام نماد.
- SELL: دایره قرمز 🔴 کنار نام نماد.
- درصد تغییر ۲۴ ساعته.
- درصد تغییر یک‌ساعته.

تغییر یک‌ساعته از آخرین قیمت بسته‌شده ۱۵ دقیقه‌ای نسبت به قیمت بسته‌شده چهار کندل قبل (یک ساعت قبل) محاسبه می‌شود. هیچ RSI یا اطلاعات اندیکاتوری دیگری در پیام سیگنال نمایش داده نمی‌شود.

BUYها ابتدا و بر اساس بیشترین تغییر ۲۴ ساعته به‌صورت نزولی مرتب می‌شوند؛ سپس SELLها بر اساس بیشترین افت ۲۴ ساعته (منفی‌ترین مقدار) مرتب می‌شوند.

## نصب و اجرا
1. محتوای ZIP را در ریشه Repository گیت‌هاب قرار دهید.
2. در `Settings → Secrets and variables → Actions` دو Repository Secret زیر را بسازید:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. اجرای GitHub Actions را فعال کنید. Workflow هر پنج دقیقه اجرا می‌شود و اجرای دستی نیز دارد.
4. Workflow پس از اجرا، `state.json` را برای جلوگیری از ارسال تکراری commit می‌کند.

اجرای محلی:

```bash
python -m pip install -r requirements.txt
python scanner.py
```

## فایل‌ها
- `scanner.py`: دریافت داده Kraken Futures، محاسبه اندیکاتورها، فیلتر BTC، مرتب‌سازی و ارسال تلگرام.
- `tests/test_logic.py`: آزمون‌های منطق سیگنال، فیلتر BTC، تازگی داده، تغییر یک‌ساعته و هم‌پوشانی زون‌ها.
- `.github/workflows/scanner.yml`: اجرای زمان‌بندی‌شده و ذخیره وضعیت.
- `.env.example`: نام متغیرهای موردنیاز؛ مقادیر واقعی را در GitHub Secrets قرار دهید و هرگز در Repository ثبت نکنید.

## محدودیت آزمون
آزمون‌های واحد و بررسی نحوی کد به‌صورت محلی انجام می‌شوند. اتصال زنده به Kraken، ارسال واقعی Telegram و اجرای GitHub Actions از این محیط قابل تأیید نیست.
