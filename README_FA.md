# اسکنر ۴ — Kraken Futures | B-Xtrender + Delta Reaction Zones

اسکنر مستقل Python برای تمام قراردادهای قابل معامله Kraken Futures در تایم‌فریم ۱۵ دقیقه. فقط کندل‌های بسته‌شده در محاسبه سیگنال استفاده می‌شوند. اسکن هر ارز مستقل است؛ BTC فقط برای اولویت‌بندی خروجی استفاده می‌شود و سیگنال‌های آلت‌کوین‌ها را فیلتر یا حذف نمی‌کند.

## قوانین قطعی

### ۱) سیگنال اولیه B-Xtrender
- فقط تغییر رنگ خط کوتاه‌مدت B-Xtrender بررسی می‌شود؛ هیستوگرام‌ها و خط روند بلندمدت دخالتی ندارند.
- تغییر رنگ روی **یک کندل بسته‌شده** کافی است و سیگنال اولیه را ایجاد می‌کند.
- سبز به قرمز (شروع قرمز) = BUY.
- قرمز به سبز (شروع سبز) = SELL.
- تغییر رنگ کندل در حال تشکیل هرگز سیگنال نیست.

### ۲) تأیید Delta Reaction Zones [BOSWaves]
- زون سبزِ حمایت = تأیید BUY؛ زون قرمزِ مقاومت = تأیید SELL.
- وجود تماس یا هم‌پوشانی High/Low حداقل یکی از **شش کندل بسته‌شده آخر** با یک زون فعال و هم‌رنگ کافی است. لازم نیست کندل تغییر رنگ B-Xtrender همان کندل لمس زون باشد.
- زون حمایت با بسته‌شدن قیمت زیر کف زون و زون مقاومت با بسته‌شدن قیمت بالای سقف زون شکسته و حذف می‌شود؛ زون شکسته‌شده تأیید نمی‌کند.
- زون‌های هم‌نوع طبق سورس اندیکاتور ادغام می‌شوند؛ تلورانس ادغام ۲۰ تیک، حداکثر ۸ زون فعال، طول پیوت ۱۲، EMA دلتا ۳، ATR(14) × ۰٫۳۵ و پنجره دلتا ۱۰۰ کندل است.
- پیوت دلتا پس از تکمیل ۱۲ کندل سمت راست شناخته می‌شود. زون از High پیوت بالایی یا Low پیوت پایینی و پهنای ATR همان کندل ساخته می‌شود.
- متن‌هایی مانند BUY FLOW / SELL FLOW / MIXED در تصمیم دخالتی ندارند؛ رنگ خود زون ملاک است.

### ۳) نقش بیت‌کوین — فقط اولویت‌بندی
- سیگنال BTC با همان قوانین B-Xtrender و Delta Reaction Zones تشخیص داده می‌شود.
- سیگنال BTC فقط جهت اولویت‌بندی خروجی را مشخص می‌کند؛ هیچ مجوز چهارکندلی، محدودیت جهت یا شرط وابستگی برای آلت‌کوین‌ها وجود ندارد.
- تمام آلت‌کوین‌ها در هر نوبت به‌صورت مستقل بررسی می‌شوند؛ حتی اگر BTC سیگنال نداشته باشد یا اولین اجرای اسکنر باشد.
- اگر آخرین سیگنال معتبر BTC BUY باشد، ابتدا BUYها و سپس SELLها می‌آیند. اگر آخرین سیگنال معتبر BTC SELL باشد، ابتدا SELLها و سپس BUYها می‌آیند.
- اگر BTC سیگنال معتبر/داده تازه نداشته باشد، ترتیب پیش‌فرض BUY سپس SELL است.
- در هر گروه، BUYها بر اساس بیشترین رشد ۲۴ساعته به‌صورت نزولی و SELLها بر اساس بیشترین افت ۲۴ساعته (منفی‌ترین درصد) مرتب می‌شوند.
- کنار سیگنال‌ها درصد تغییر ۲۴ساعته، RSI ارز، RSI بیت‌کوین و رنگ دو کندل بسته‌شده آخر B-Xtrender بیت‌کوین نمایش داده می‌شود.
- اگر BTC سیگنال تازه بدهد، خط BTC در ابتدای پیام درج می‌شود و در صورت وجود سیگنال قبلی، جهت قبلی و فاصله کندلی نیز نمایش داده می‌شود.

### ۴) تازگی داده و جلوگیری از تکرار
- کندل بسته‌شده زمانی stale است که بیش از ۱۵ دقیقه از زمان بسته‌شدن آن گذشته باشد.
- برای هر نماد، اگر آخرین کندل بسته‌شده بیش از ۱۵ دقیقه قدیمی باشد، هیچ سیگنالی از آن نماد اعلام نمی‌شود و در گزارش تشخیصی stale ثبت می‌شود.
- اگر کندل BTC stale باشد، جهت BTC برای اولویت‌بندی استفاده نمی‌شود؛ اسکن مستقل آلت‌کوین‌ها ادامه پیدا می‌کند.
- کلید نماد/تایم‌فریم/زمان کندل/جهت از طریق زمان آخرین کندل سیگنال هر نماد در `state.json` از ارسال تکراری جلوگیری می‌کند.
- خطای دریافت یا تحلیل یک قرارداد، اسکن سایر قراردادها را متوقف نمی‌کند.
- گزارش GitHub Actions تعداد بازارها، سیگنال‌ها، تاریخچه ناکافی، نبود تغییر رنگ، نبود تماس زون، کندل قدیمی، تکراری‌ها و خطاها را ثبت می‌کند.

## راه‌اندازی GitHub Actions و تلگرام

1. محتوای ZIP را در ریشه یک GitHub Repository قرار دهید.
2. در `Settings → Secrets and variables → Actions` دو Repository Secret بسازید:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. در تب Actions اجرای Workflow را فعال کنید. اجرای زمان‌بندی‌شده هر پنج دقیقه است و اجرای دستی نیز فعال است.
4. Workflow پس از اجرا تغییرات `state.json` را commit و push می‌کند.

## اجرای محلی

```bash
python -m pip install -r requirements.txt
# TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID را در محیط تنظیم کنید
python scanner.py
```

## نکات فنی
- از API عمومی Kraken Futures استفاده می‌شود؛ API Key خصوصی صرافی لازم نیست.
- محاسبه Delta از `sign(close-open) × volume`، هموارسازی EMA(3) و تجمع دلتا انجام می‌شود؛ منبع پیوت پیش‌فرض مطابق سورس ارسالی `Cumulative Delta` است.
- ATR با RMA و طول ۱۴ محاسبه می‌شود.
- ۲۲۰ کندل اخیر برای بازسازی اندیکاتورها دریافت می‌شود؛ بنابراین زون‌هایی که قبل از این محدوده ایجاد شده‌اند قابل بازسازی نیستند.
- این پروژه فقط هشدار می‌فرستد و سفارش معاملاتی ثبت نمی‌کند.
