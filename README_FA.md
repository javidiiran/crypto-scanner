# اسکنر شماره دو — Kraken Futures (CNV + RSI)

## قوانین ثابت
- فقط Kraken Futures Perpetual؛ تایم‌فریم ۱ ساعته.
- فقط کندل‌های کاملاً بسته‌شده بررسی می‌شوند؛ کندل در حال تشکیل حذف می‌شود.
- CNV: تغییر مثبت قیمت = حجم مثبت، تغییر منفی = حجم منفی، بدون تغییر = صفر؛ CNV تجمعی و خط مبنا SMA(20).
- CNV آبی وقتی `CNV - SMA(CNV,20) > 0` و در غیر این صورت صورتی است.
- BUY: سه کندل بسته‌شده صورتی، آبی، آبی؛ حداقل یکی از RSIهای همان سه کندل (RSI Wilder دوره ۱۴) کمتر از ۵۰ باشد.
- SELL: سه کندل بسته‌شده آبی، صورتی، صورتی؛ حداقل یکی از RSIهای همان سه کندل بیشتر از ۵۰ باشد.
- سیگنال روی بسته‌شدن کندل سوم تأیید می‌شود.
- BTC در ابتدای هر اجرا بررسی می‌شود و اگر روی آخرین کندل بسته‌شده سیگنال داشته باشد، پیام BTC قبل از پیام‌های آلت‌کوین ارسال می‌شود. نبود سیگنال جدید BTC مانع اسکن آلت‌کوین‌ها نیست. جهت BTC فیلتر جهت سیگنال آلت‌کوین‌ها نیست؛ سیگنال‌های معتبر BUY و SELL آلت‌کوین‌ها مستقل گزارش می‌شوند. کنار هر سیگنال، RSI ارز و اطلاعات آخرین سیگنال BTC، دو رنگ آخر CNV بیت‌کوین و RSI فعلی BTC درج می‌شود.
- سیگنال‌ها با شناسه نماد/زمان/جهت تکراری ارسال نمی‌شوند.

## فایل موتور AB
- فایل `ob_sqzmom_engine.py` موتور محاسباتی اسکنر است و منطق CNV + RSI در آن قرار دارد. این فایل در بسته ZIP موجود است.
- فایل `indicator_engine.py` فقط لایه سازگاری برای نام قدیمی ماژول است.

## راه‌اندازی
1. فایل‌ها را در مخزن GitHub بارگذاری کنید.
2. در Settings → Secrets and variables → Actions دو Secret بسازید: `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`.
3. اجرای دستی workflow با `workflow_dispatch` فعال است؛ زمان‌بندی هر ساعت در دقیقه ۵ انجام می‌شود.
4. در Actions گزینه Run workflow را اجرا کنید.

## نکته
این نسخه برای اجرای GitHub Actions آماده شده است. ارتباط زنده Kraken و ارسال واقعی تلگرام فقط هنگام اجرای workflow در حساب شما قابل آزمون است.
