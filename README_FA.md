# اسکنر Kraken Derivatives — بازسازی موتور BTC Phase + SQZMOM + Order Blocks

## تنظیمات اجرایی
- صرافی: Kraken Derivatives
- بازار: فقط Futures Perpetual با پیشوندهای `PF_` و `PI_`؛ Spot و قراردادهای تاریخ‌دار وارد نمی‌شوند.
- تایم‌فریم: ۳۰ دقیقه
- داده: فقط کندل‌های بسته‌شده
- اجرا: GitHub Actions هر ۵ دقیقه
- خروجی: تلگرام؛ بدون ثبت سفارش و بدون معامله خودکار
- API خصوصی صرافی لازم نیست.

## منطق قطعی موتور

### ۱) جهت بازار از SQZMOM بیت‌کوین
- ابتدا فقط BTC بررسی می‌شود.
- آخرین قله معتبر BTC: سه میله بسته‌شده متوالی بالای صفر و میله وسط قله سخت‌گیرانه باشد؛ جهت فعال آلت‌کوین‌ها `SELL / SHORT` می‌شود.
- آخرین دره معتبر BTC: سه میله بسته‌شده متوالی زیر صفر و میله وسط دره سخت‌گیرانه باشد؛ جهت فعال آلت‌کوین‌ها `BUY / LONG` می‌شود.
- این جهت تا تأیید قله/دره مخالف بعدی BTC حفظ می‌شود.
- اگر BTC هیچ قله/دره سه‌میله‌ای تأییدشده‌ای در داده‌های موجود نداشته باشد، اسکن آلت‌کوین‌ها متوقف می‌شود؛ جهت حدسی ساخته نمی‌شود.
- کندل BTC و آلت‌کوین باید زمان بسته‌شدن یکسان داشته باشند.

### ۲) تریگر SQZMOM هر آلت‌کوین
- `SELL`: سه میله آخر بسته‌شده همگی بالای صفر؛ میله وسط از هر دو طرف بلندتر باشد.
- `BUY`: سه میله آخر بسته‌شده همگی زیر صفر؛ میله وسط از هر دو طرف عمیق‌تر باشد.
- فقط سیگنال هم‌جهت با فاز BTC پذیرفته می‌شود.
- هیچ ضریب ۱٫۵، حداقل ارتفاع یا فیلتر قدرتی وجود ندارد.
- هیچ کندل در حال تشکیل در محاسبه وارد نمی‌شود.

### ۳) فیلتر SMC — فقط باکس‌های واقعی سبز/قرمز Order Block
- منطق محاسباتی از فایل قبلی `Order Blocks Zones with Signals — Uncle_the_shooter` منتقل شده است.
- باکس سبز = Bullish OB و فقط می‌تواند BUY را تأیید کند.
- باکس قرمز = Bearish OB و فقط می‌تواند SELL را تأیید کند.
- برای تأیید سیگنال، حداقل یکی از پنج کندل بسته‌شده آخر باید با باکس فعال هم‌رنگ سیگنال تماس داشته باشد.
- تماس با هر بخش از محدوده باکس از طریق High/Low کندل کافی است؛ بسته‌شدن Close داخل باکس الزامی نیست.
- پنج کندل آخر نسبت به کندل سیگنال سنجیده می‌شوند و باکس باید در زمان کندل سیگنال همچنان فعال باشد.
- باکس‌های Premium، Discount، Equilibrium یا Reversal Probability جایگزین OB نیستند و در تأیید سیگنال دخالت ندارند.
- پارامترهای OB: Pivot Length=10، Use Wicks=true، Candle Size Period=20، OB Size Multiplier=0.1، حداکثر عمر باکس=500 کندل.

### ۴) جلوگیری از خطا
- جهت BTC یک فیلتر سخت است؛ سیگنال خلاف آن حذف می‌شود.
- BUY و SELL هم‌زمان برای یک نماد/کندل ممنوع است.
- سیگنال بدون باکس هم‌جهت ممنوع است.
- سیگنال تکراری برای همان نماد، کندل، جهت و فاز BTC دوباره ارسال نمی‌شود.
- هر هشدار، جهت BTC و دلیل تأیید OB را گزارش می‌کند.

## فایل‌ها
- `scanner.py`: Kraken API، فاز BTC، اسکن Perpetualها و تلگرام.
- `indicator_engine.py`: SQZMOM و منطق Order Blocks سبز/قرمز.
- `test_engine.py`: آزمون قله/دره سه‌میله‌ای، باکس هم‌جهت، عدم سیگنال بیرون باکس، و جهت BTC.
- `test_scanner_api.py`: آزمون قراردادهای Perpetual، کندل بسته و فیلتر جهت BTC.
- `.github/workflows/scan.yml`: اجرای زمان‌بندی‌شده.
- `state.json`: جلوگیری از هشدار تکراری.

## نصب
1. ZIP را استخراج و تمام محتویات پوشه `Kraken_Derivatives_Scanner` را در ریشه مخزن GitHub جایگزین کنید.
2. مسیر `.github/workflows/scan.yml` را حفظ کنید.
3. Secrets قبلی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را نگه دارید؛ نیازی به تغییرشان نیست.
4. در Actions مجوز `Read and write` برای Contents لازم است.
5. ابتدا `Run workflow` را دستی اجرا کنید و گزارش اجرا را ببینید.

## تست و محدودیت
- تست‌های آفلاین با `python -m unittest -v` اجرا می‌شوند.
- این نسخه در محیط ساخت با تست‌های آفلاین بررسی شده است؛ اتصال زنده Kraken و تحویل واقعی تلگرام از این محیط قابل تأیید نیست.
- اجرای هر ۵ دقیقه تقریبی است؛ سیگنال فقط بعد از بسته‌شدن کندل ۳۰ دقیقه‌ای جدید امکان‌پذیر است.


## نسخه 2.1 — گزارش تشخیصی

این نسخه فقط گزارش مرحله‌به‌مرحله اضافه می‌کند و قوانین معاملاتی نسخه 2.0 را تغییر نمی‌دهد. در لاگ GitHub Actions، تعداد قله‌ها و دره‌های سه‌میله‌ای، تأیید باکس سبز/قرمز، رد شدن به‌علت جهت BTC، اختلاف زمان کندل‌ها، داده ناقص و تعداد سیگنال‌های آماده نمایش داده می‌شود. برای مشاهده گزارش، اجرای معمول Workflow کافی است.


## منطق نسخه 2.2

- قله سه‌میله‌ای SQZMOM بیت‌کوین بالای صفر، فاز SELL را فعال می‌کند؛ این فاز تا تشکیل دره سه‌میله‌ای زیر صفر ادامه دارد.
- دره سه‌میله‌ای SQZMOM بیت‌کوین زیر صفر، فاز BUY را فعال می‌کند؛ این فاز تا تشکیل قله سه‌میله‌ای بالای صفر ادامه دارد.
- آلت‌کوین فقط در جهت فاز فعال BTC و با تأیید Order Block رنگی متناظر SMC سیگنال می‌دهد. حداقل یکی از پنج کندل آخر باید محدوده باکس فعال هم‌رنگ را با High/Low لمس کرده باشد؛ بسته‌شدن داخل باکس لازم نیست.
- خود BTC از تأیید SMC معاف است و هنگام تأیید پیوت سه‌میله‌ای جدید خودش می‌تواند هشدار بدهد.
- نرم‌افزار Reversal و تمام نسبت‌ها و محاسبات وابسته به آن در این نسخه وجود ندارند.
- منطق Order Block، قله/دره سه‌میله‌ای، فیلتر جهت BTC، بازار Kraken Perpetual و تایم‌فریم ۳۰ دقیقه حفظ شده‌اند.


## منطق نسخه 2.3

- تأیید SMC برای آلت‌کوین‌ها با پنجره پنج کندل بسته‌شده انجام می‌شود.
- در هر کندل سیگنال، پنج کندل آخر با باکس‌های هم‌رنگی بررسی می‌شوند که در همان زمان هنوز فعال‌اند.
- تماس سایه یا بدنه با محدوده باکس کافی است؛ Close لازم نیست داخل باکس باشد.
- باکس سبز فقط BUY و باکس قرمز فقط SELL را تأیید می‌کند.
- BTC همچنان از تأیید SMC معاف است؛ تمام قواعد SQZMOM سه‌میله‌ای و فاز BTC بدون تغییر مانده‌اند.
