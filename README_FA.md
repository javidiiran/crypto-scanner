# اسکنر Kraken Derivatives — Perpetual — SQZMOM + SMC

## تنظیمات قطعی
- صرافی: Kraken Derivatives
- بازار: قراردادهای Perpetual فیوچرز؛ نمادهای با پیشوند `PF_` و `PI_` که در فهرست ابزارهای Kraken ارائه شده‌اند.
- تایم‌فریم: ۳۰ دقیقه
- داده: کندل‌های Trade؛ فقط کندل‌های بسته‌شده
- اجرای زمان‌بندی‌شده: هر ۵ دقیقه با GitHub Actions
- خروجی: هشدار تلگرام؛ بدون ثبت سفارش و بدون معامله خودکار
- نیاز به API Key/Secret صرافی ندارد؛ داده‌های بازار از endpointهای عمومی خوانده می‌شوند.

## منطق سیگنال
1. **SQZMOM تریگر اصلی** است: سه میله بسته‌شده آخر باید همگی بالای صفر با قله در میله وسط باشند (SELL)، یا همگی زیر صفر با دره در میله وسط باشند (BUY).
2. **SMC تنها تأییدکننده** است: تماس سایه (High/Low) یکی از پنج کندل بسته‌شده آخر با ناحیه هم‌جهت SMC کافی است؛ Close لازم نیست داخل باکس باشد.
3. **Reversal نماد** فقط اطلاعات جانبی است و سیگنال را رد یا تغییر نمی‌دهد. رنگ و محدوده باکس در هشدار گزارش می‌شود.
4. **Reversal بیت‌کوین** نیز در هر هشدار فقط برای اطلاع گزارش می‌شود و شرط تأیید نیست.
5. از هر قرارداد، برای هر کندل و جهت فقط یک هشدار تلگرام ارسال می‌شود.

## APIهای Kraken
- فهرست قراردادها: `GET https://futures.kraken.com/derivatives/api/v3/instruments`
- کندل‌ها: `GET https://futures.kraken.com/api/charts/v1/trade/{symbol}/30m`
- قراردادهای تاریخ‌دار، Spot و Options وارد اسکن نمی‌شوند.

## نصب در GitHub
1. محتوای این پوشه را در ریشه Repository بارگذاری کنید؛ ساختار `.github/workflows/scan.yml` باید حفظ شود.
2. در Repository → Settings → Secrets and variables → Actions دو Secret بسازید:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. در Settings → Actions → General، دسترسی Workflow به `Read and write` فعال باشد تا `state.json` به‌روزرسانی شود.
4. از زبانه Actions، workflow را با `Run workflow` دستی اجرا کنید.

## نکات تست و محدودیت
- تست‌های محاسبات اندیکاتور با `python -m unittest -v` اجرا می‌شوند.
- این بسته در محیط ساخت فعلی از نظر نحوی و تست‌های آفلاین قابل بررسی است؛ دسترسی شبکه این محیط به Kraken برقرار نبود، بنابراین اتصال زنده و پاسخ واقعی endpointها در اینجا تأیید نشده است. اولین اجرای GitHub Actions باید اتصال زنده را بررسی کند.
- زمان‌بندی GitHub Actions تقریبی است و تضمین اجرای دقیقاً در هر دقیقه پنجم را نمی‌دهد.
- در صورت تغییر قالب پاسخ API یا محدودیت منطقه‌ای/شبکه‌ای، خطا در گزارش اجرای Workflow ظاهر می‌شود؛ اسکنر به Spot یا صرافی دیگری تغییر مسیر نمی‌دهد.
